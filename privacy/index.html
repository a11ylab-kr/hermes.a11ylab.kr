개인정보처리방침

본 방침은 김찬홍(이하 “운영자”)이 개인적으로 운영하는 Hermes-Agent Google Workspace 연동이 Google 사용자 데이터를 어떻게 접근·사용·저장·공유·삭제하는지 설명합니다.

1. 적용 범위

이 OAuth 앱은 운영자 본인의 Google 계정에서 로컬 Hermes-Agent를 사용하기 위한 개인용 도구입니다. 일반 사용자를 모집하거나 계정 또는 기능을 불특정 다수에게 제공하지 않습니다.

이 공개 안내 사이트(hermes.a11ylab.kr)는 Google 사용자 데이터를 직접 수집하거나 처리하지 않으며, 분석 스크립트·쿠키·입력 양식을 사용하지 않습니다.

2. 접근하는 Google 사용자 데이터와 권한

표가 화면보다 넓으면 가로로 스크롤할 수 있습니다.

실제 OAuth 권한 범위는 Google 동의 화면에 표시되며, 운영자는 기능 수행에 필요한 범위에서만 접근을 요청합니다.

3. 데이터 사용 목적

Google 사용자 데이터는 운영자가 Hermes-Agent에 명시적으로 지시한 작업을 수행하기 위해 사용합니다. 사용 목적에는 다음이 포함됩니다.

  • 일정 검색·요약·정리와 일정 생성·변경
  • 이메일 검색·요약·초안 작성·발송과 메일 상태 관리
  • Drive 파일 검색·조회·정리·업로드·다운로드·공유
  • Docs와 Sheets 문서 조회·작성·수정
  • 연락처 조회

데이터를 광고, 맞춤형 광고, 데이터 판매, 데이터 중개, 신용평가, 대출, 감시 목적으로 사용하지 않습니다.

4. 저장 위치와 보존 기간

  • OAuth 자격 증명과 토큰: 운영자가 관리하는 기기의 로컬 Hermes 데이터 디렉터리에 저장됩니다. 이 공개 사이트나 사이트 호스팅 저장소에는 저장하지 않습니다.
  • 작업 결과와 세션 기록: 작업의 연속성과 검토를 위해 운영자의 로컬 기기에 저장될 수 있습니다.
  • 보존 기간: 로컬 기록은 운영 목적상 필요한 동안 또는 운영자가 삭제할 때까지 보관합니다. OAuth 토큰은 접근 권한을 철회하거나 로컬 토큰을 삭제할 때까지 보관할 수 있습니다.

5. 데이터 전송과 공유

작업 수행에 필요한 범위에서 Google 사용자 데이터가 다음 수신자에게 전송되어 처리될 수 있습니다.

  • Google API: 운영자가 요청한 Google Workspace 기능을 실행하기 위해 사용합니다.
  • 운영자가 선택한 AI 모델 제공자: 검색 결과의 해석, 요약, 문서 작성 또는 도구 실행 판단 등 운영자가 요청한 기능을 제공하기 위해 필요한 데이터가 전송될 수 있습니다. 해당 제공자의 데이터 처리와 보존에는 운영자가 선택한 서비스의 계약·설정·정책이 적용됩니다.

위 전송은 운영자가 요청한 기능을 제공하기 위한 목적에 한정합니다. Google 사용자 데이터를 광고 플랫폼, 데이터 브로커 또는 정보 재판매자에게 판매하거나 이전하지 않습니다.

6. Google API Services User Data Policy 준수

Hermes-Agent의 Google API를 통해 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요건(Limited Use requirements)을 포함한 Google API Services User Data Policy를 준수합니다.

7. 보안

운영자는 OAuth 클라이언트 자격 증명과 토큰을 공개 저장소나 공개 웹페이지에 게시하지 않으며, 로컬 파일 접근 통제와 전송 구간 암호화(HTTPS)를 사용합니다. 다만 어떠한 저장 또는 전송 방식도 절대적인 보안을 보장할 수는 없습니다.

8. 접근 권한 철회와 데이터 삭제

운영자는 언제든지 다음 방법으로 접근과 로컬 데이터를 통제할 수 있습니다.

  • Google 계정의 서드 파티 연결 페이지에서 Hermes-Agent의 접근 권한 철회
  • 로컬 Hermes 환경에서 OAuth 토큰과 관련 세션·작업 기록 삭제
  • Google 서비스 안에서 생성·변경된 데이터는 각 Google 서비스의 삭제·복구 기능으로 관리

9. 방침 변경

접근 범위나 데이터 처리 방식이 달라지면 이 문서를 갱신하고 시행일을 변경합니다. 새로운 목적이나 범위로 Google 사용자 데이터를 사용하기 전에 필요한 고지와 동의 절차를 거칩니다.
